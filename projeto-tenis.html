Passo Certo

Uma loja fictícia criada por nós para demonstrar como fica um site de melhores preços de tênis no mercado.

Sobre o projeto

O Passo Certo é um site (protótipo) de uma loja de tênis fictícia criada pela GraVit Tech, com o foco em melhores e mais baratos tênis de diversas categorias, com visual moderno e funcionando bem no celular. Além de poder fazer e-commerce podemos fazer um site de catálogos como este ou da sua preferência.

O site foi pensado com acessibilidade: dá para navegar só com o teclado, os contrastes seguem as boas práticas e os leitores de tela anunciam o que acontece na página.

Principais recursos

  • Vitrine de produtos com filtros por categoria
  • Botão de ir ao site oficial para realizar a compra
  • Layout responsivo para celular e computador
  • Acessível por teclado e leitor de tela
